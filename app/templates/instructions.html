📹 Guia Completo de Conversão de Vídeos com FFmpeg

💡 O que é FFmpeg?
FFmpeg é uma ferramenta de linha de comando poderosa e gratuita para processamento de áudio e vídeo. É usado mundialmente por desenvolvedores, editores de vídeo e empresas para conversão, compressão e manipulação de mídia.

🔧 Instalação do FFmpeg

Windows:

# Opção 1: Via Chocolatey
choco install ffmpeg

# Opção 2: Via Scoop  
scoop install ffmpeg

# Opção 3: Download manual do site oficial
# Baixe de: https://ffmpeg.org/download.html#build-windows

macOS:

# Via Homebrew (recomendado)
brew install ffmpeg

# Via MacPorts
sudo port install ffmpeg

Linux (Ubuntu/Debian):

# Atualizar repositórios
sudo apt update

# Instalar FFmpeg
sudo apt install ffmpeg

# Verificar instalação
ffmpeg -version

📋 Comandos Básicos de Conversão

Conversão Básica entre Formatos

# Converter MP4 para AVI
ffmpeg -i video.mp4 video.avi

# Converter AVI para MKV
ffmpeg -i video.avi video.mkv

# Converter MKV para MP4
ffmpeg -i video.mkv video.mp4

⚙️ Parâmetros Avançados

Parâmetro Descrição Exemplo
-i Especifica o arquivo de entrada -i video.mp4
-c:v Define o codec de vídeo -c:v libx264
-c:a Define o codec de áudio -c:a aac
-b:v Define o bitrate do vídeo -b:v 1M
-b:a Define o bitrate do áudio -b:a 128k
-s Define a resolução -s 1920x1080
-r Define o frame rate -r 30
-y Sobrescreve arquivos existentes -y

🎯 Exemplos Práticos Avançados

Reduzir Tamanho do Arquivo (Compressão)

# Compressão alta qualidade
ffmpeg -i input.mp4 -c:v libx264 -crf 23 -c:a aac -b:a 128k output.mp4

# Compressão máxima (menor qualidade)
ffmpeg -i input.mp4 -c:v libx264 -crf 30 -c:a aac -b:a 64k output.mp4

Alterar Resolução

# Converter para HD (1280x720)
ffmpeg -i input.mp4 -s 1280x720 -c:v libx264 -c:a aac output_hd.mp4

# Converter para Full HD (1920x1080)
ffmpeg -i input.mp4 -s 1920x1080 -c:v libx264 -c:a aac output_fhd.mp4

# Redimensionar mantendo proporção
ffmpeg -i input.mp4 -vf scale=1280:-1 -c:v libx264 -c:a aac output.mp4

Extrair Áudio do Vídeo

# Extrair como MP3
ffmpeg -i video.mp4 -vn -c:a mp3 -b:a 192k audio.mp3

# Extrair como AAC
ffmpeg -i video.mp4 -vn -c:a aac -b:a 128k audio.aac

# Extrair sem recodificar
ffmpeg -i video.mp4 -vn -c:a copy audio.aac

Cortar/Trimmar Vídeo

# Cortar do segundo 30 ao 90 (1 minuto de duração)
ffmpeg -i input.mp4 -ss 30 -t 60 -c copy output.mp4

# Cortar os primeiros 10 segundos
ffmpeg -i input.mp4 -ss 10 -c copy output.mp4

# Cortar do minuto 2 ao minuto 5
ffmpeg -i input.mp4 -ss 00:02:00 -to 00:05:00 -c copy output.mp4

🚀 Conversão em Lote

Windows (PowerShell)

# Converter todos os MP4 para AVI
Get-ChildItem *.mp4 | ForEach-Object {
    ffmpeg -i $_.Name -c:v libx264 -c:a aac ($_.BaseName + ".avi")
}

Linux/macOS (Bash)

# Converter todos os MP4 para AVI
for file in *.mp4; do
    ffmpeg -i "$file" -c:v libx264 -c:a aac "${file%.mp4}.avi"
done

# Comprimir todos os vídeos na pasta
for file in *.mp4; do
    ffmpeg -i "$file" -c:v libx264 -crf 23 -c:a aac "compressed_${file}"
done
⚠️ Dicas Importantes:
  • Sempre faça backup dos arquivos originais antes de converter
  • Use o parâmetro -y para sobrescrever arquivos automaticamente
  • O valor CRF entre 18-28 oferece boa qualidade (18 = melhor qualidade, 28 = menor arquivo)
  • Para conversões longas, considere usar -progress para acompanhar o progresso
  • Verifique sempre se o arquivo de saída foi gerado corretamente

📊 Obter Informações do Vídeo

# Informações detalhadas do arquivo
ffprobe -v quiet -print_format json -show_format -show_streams video.mp4

# Informações básicas
ffmpeg -i video.mp4 -f null - 2>&1 | head -20
